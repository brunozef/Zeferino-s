# Zeferino's content machine

Daily Reels and Stories for @zeferinosprecisionfinish, made from the company's own project photos and footage.

- `make_reel.py spec.json` renders a 9:16 video (Reel or Story) with animated captions, the Zeferino's logo, a Free Estimate ending and original royalty-free music. Run it from the repository root.
- `footage/` holds raw job-site clips. `../images/` holds the project photos used on the site.
- `out/` holds approved videos only, so Instagram can fetch them from zeferinosusa.com when publishing.

Rules: nothing is published before Zeferino's Precision Finish approves it, and nothing is ever boosted or paid.
